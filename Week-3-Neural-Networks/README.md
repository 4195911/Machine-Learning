# Week 3 — Neural Networks

Implemented neural networks using Python and NumPy.

## Projects

- **001 XOR Logistic Regression** — Demonstrated why a linear classifier cannot solve the XOR problem.
- **002 XOR Neural Network** — Implemented a neural network with a hidden layer to solve XOR.
- **003 Gradient Checking** — Verified analytical gradients against numerical gradients.
- **004 Handwritten Digit Recognition** — Built a neural network using ReLU, softmax, mini-batch SGD, and L2 regularization.

## Results

- XOR neural network: 100% accuracy.
- Gradient checking: Analytical and numerical gradients matched closely.
- Handwritten digit classifier: 95.60% test accuracy with L2 regularization.
- Previous experiment without L2: 95.73% test accuracy.

## Dataset

- MNIST handwritten digits (CSV format).
- 784 pixel features per image (28 × 28).
- Dataset: https://www.kaggle.com/competitions/digit-recognizer/data
- Download `train.csv` and rename it to `handwritten_digit.csv`.
- The dataset is not included in this repository.
