- 001 binary_cross_entropy.py — Implemented binary cross-entropy loss from scratch using NumPy

## Dataset

- Dataset: MNIST handwritten digits in CSV format.
- Each image contains 784 pixel values (28 × 28).
- Download: https://www.kaggle.com/competitions/digit-recognizer/data
- Download train.csv and rename it to handwritten_digit.csv.
- Place it in the project folder before running the handwritten digit scripts.
- The dataset is not included in this repository.
